# github-final-project
# Coursera Git Project

## 📌 About the Project

This repository was created as part of my Coursera course to practice Git and GitHub fundamentals, version control, and repository management.

## 🎯 Objectives

* Understand Git and GitHub basics.
* Learn to create and manage repositories.
* Practice committing and pushing changes.
* Learn how to create and maintain project documentation.
* Understand open-source contribution guidelines.

## 🛠️ Tools Used

* Git
* GitHub
* Markdown

## 📂 Repository Contents

* `README.md` — Project overview and documentation.
* `CODE_OF_CONDUCT.md` — Community standards and guidelines.
* `CONTRIBUTING.md` — Guidelines for contributing to the project.

## 🚀 What I Learned

* Creating and managing a GitHub repository.
* Using Git for version control.
* Writing documentation using Markdown.
* Creating a Code of Conduct.
* Writing contribution guidelines.
